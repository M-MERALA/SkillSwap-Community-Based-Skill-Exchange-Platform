# ✨ SkillSwap — Community-Based Skill Exchange Platform

A modern Flutter mobile application designed for collaborative learning, skill exchange, and interactive communities.

---

# 📱 Overview

SkillSwap is a community-driven mobile application that helps users exchange skills, connect with mentors, join learning communities, and grow together through interactive experiences.

Users can:
- Teach skills they already know
- Learn from others
- Join communities
- Ask questions
- Communicate through chat
- Build collaborative learning relationships

- Login & Sign Up

- Ask questions
- Community discussions
- Shared resources & folders

## 🤝 Skill Swapping

- Manage sent & received requests
- Public user profiles

# 🧪 Usability Testing

Usability testing was conducted using Maze to evaluate:
- Account creation flow
- Profile image upload
- Joining communities
- Asking questions
- Sending swap requests
- Opening chats

The testing helped improve:
- Navigation
- Interaction flow
- User experience
- Accessibility
